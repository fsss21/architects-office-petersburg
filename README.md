# Классический Петербург

## Краткое описание ПО

Интерактивный киоск зала «Классический Петербург» музея «Уткина дача». Посвящён традициям городской скульптуры XVIII–XIX веков и роли памятников в образе столицы. Включает тематические тексты и каталог скульптур с фильтрами.

## Сценарий работы ПО

### Стартовый экран

Полноэкранная заставка. Касание экрана открывает главное меню.

### Главное меню

Заголовок «КЛАССИЧЕСКИЙ ПЕТЕРБУРГ». Карусель из трёх тем:

- Формирование традиций городской скульптуры в XVIII–XIX веках
- Скульптура имперского периода
- Роль памятников в формировании образа новой столицы

Кнопки:

- **Подробнее** — экран темы (SubMenu)
- **Перейти в каталог** — сразу в каталог скульптур
- **Назад** — без перехода внутри приложения (возврат во внешнюю оболочку)

### Экран темы (SubMenu)

Три темы на линии прогресса, текст и фото.  
**Назад** → главное меню.  
**Перейти в каталог** → каталог.

### Каталог и карточка объекта

Фильтры (скульпторы, эпохи, материал), поиск, сетка объектов. Нажатие открывает карточку. **Назад** → главное меню.
